# Interactive Walkthrough Video

This folder contains the live system walkthrough animation.

- **Walkthrough Recording:** [runtime_demo.webp](runtime_demo.webp)

It records the complete end-to-end integration flow on the local environment:
1. Local server startup
2. Landing on the Nyaya AI dashboard and logging in as Guest
3. Submitting the query: `"punishment for theft"`
4. Verifying the reasoning trace, jurisdiction detection (India), applicable sections (IPC 378/379), remedies, and procedural steps
5. Navigating to the FastAPI Swagger UI (`/docs`) to verify available ecosystem and reasoning endpoints
6. Checking the system readiness endpoint (`/health/ready`)
7. Checking the ecosystem Bucket health endpoint (`/ecosystem/bucket/health`)

*Note: The demo is recorded in high-performance WebP format, which can be viewed natively in any modern browser.*
